# 術科考試抽題 PWA

一個可安裝、可離線使用的瀏覽器抽題工具。程式本身不內建正式題庫；教師自行從裝置匯入 `.xlsx` 題庫，資料保存在該裝置的瀏覽器儲存空間中。

## 開始使用

GitHub Pages：

https://suyanali.github.io/exam-pwa/

第一次使用請在有網路的環境開啟上述網址，等待頁面顯示離線功能已就緒，再匯入題庫。若要在沒有網路的環境使用，建議安裝成 App／加入主畫面，並在正式考試前開飛航模式實測一次。

## 題庫格式

Excel 第一列固定使用以下四個欄位：

| 大題 | 單元 | 題號 | 題目 |
|---|---|---|---|
| 1 | Unit A | 1-01 | 第一大題範例 |
| 2 | Unit A | 2-01 | 第二大題範例 |
| 3 | Unit B | 3-01 | 第三大題範例 |

- `大題`：可為 1、2、3……，程式會依匯入內容自動判斷大題數量；只有一大題也可以。
- `單元`：供抽題配對使用，不顯示在學生考試畫面。
- `題號`：顯示用識別碼。
- `題目`：可使用中文、英文或中英混合。
- 教師設定可指定後續大題「不限單元隨機抽題」，或「與前面指定大題同單元」。

程式內也提供「下載空白範本」、「匯入題庫」及「匯出目前題庫」。

## Windows

1. 使用 Chrome 或 Microsoft Edge 開啟 GitHub Pages 網址。
2. 第一次保持網路連線，等待「離線功能已就緒」。
3. 若頁面出現「安裝 App」，直接按下；也可使用瀏覽器網址列或選單中的「安裝應用程式」。
4. 匯入題庫。
5. 之後可從開始功能表／桌面開啟 App。需要離線使用時，正式考試前請斷網重新開啟一次確認。

## macOS

1. 使用支援安裝網站 App 的瀏覽器開啟 GitHub Pages 網址。
2. 第一次保持網路連線並等待離線功能就緒。
3. Chrome 可使用「安裝 App」；新版 Safari 可使用「檔案 > 加入 Dock」（實際名稱依 macOS / Safari 版本而異）。
4. 匯入題庫後即可使用。需要離線時請先斷網實測。

## Android

1. 使用 Chrome 開啟 GitHub Pages 網址。
2. 第一次保持網路連線，等待離線功能就緒。
3. 若頁面顯示「安裝 App」，直接按下；也可從 Chrome 選單選「安裝應用程式」或「加入主畫面」。不同 Chrome / Android 版本顯示文字可能不同。
4. 從主畫面圖示開啟後匯入題庫。
5. 需要離線時，開啟飛航模式、完全關閉 App，再從主畫面圖示重新開啟測試。

## iPhone / iPad（iOS / iPadOS）

1. 建議使用 Safari 開啟 GitHub Pages 網址。
2. 第一次保持網路連線，等待離線功能就緒。
3. 點 Safari 的「分享」按鈕，再選「加入主畫面」。
4. 從主畫面圖示開啟 App，匯入題庫。
5. 需要離線時，開啟飛航模式、完全關閉 App，再從主畫面圖示重新開啟測試。

> iOS / iPadOS 不一定會像 Android Chrome 一樣出現網站內的 PWA 安裝提示，因此以 Safari 的「加入主畫面」為準。

## 本機資料與完整清除

題庫與抽題規則主要存放在瀏覽器的 **IndexedDB**，不是單純存在 Cookie。因此只按「清除 Cookie」不一定能完整移除題庫。

最簡單的方法是在「教師設定」按 **清除本機題庫與設定**。這會清除本 App 儲存的題庫與抽題規則，但不會刪除 GitHub 上的程式。

如果需要從瀏覽器層級完全重置，可清除此網站的「網站資料／儲存空間」。這通常會同時清除 IndexedDB、Cache Storage、Service Worker 等資料；各作業系統與瀏覽器的選單名稱可能不同。若已安裝成 App，也可先移除 App，再清除該網站資料後重新安裝。

## 離線注意事項

PWA 第一次載入與安裝需要網路。看到離線功能已就緒後，仍建議在正式使用前做一次完整測試：匯入題庫 → 關閉 App → 開飛航模式 → 從 App 圖示重新開啟 → 抽題 → 倒數 → 匯出題庫。

## 隱私

正式題庫不會因為匯入而寫入此 GitHub repository。題庫及教師抽題規則保存在使用該網站／App 的裝置中。不同裝置之間不會自動同步題庫。
