# 術科考試抽題 PWA

一個可安裝、可離線使用的瀏覽器抽題工具。程式本身不內建正式題庫；教師自行匯入 `.xlsx` 題庫，資料只保存在目前使用的裝置。

## 開始使用

**GitHub Pages：** https://suyanali.github.io/exam-pwa/

第一次使用時請先連上網路並開啟上方網址。若之後需要離線使用，請依下方作業系統說明安裝 App／加入主畫面，並先用飛航模式測試一次。

## 題庫格式

Excel 第一列固定使用以下四個欄位：

| 大題 | 單元 | 題號 | 題目 |
|---|---|---|---|
| 1 | Unit A | 1-01 | 第一大題範例 |
| 2 | Unit A | 2-01 | 第二大題範例 |
| 3 | Unit B | 3-01 | 第三大題範例 |

- `大題`：可為 1、2、3……；只有一大題也可以。
- `單元`：供抽題配對使用，不會顯示給學生。
- `題號`：顯示用識別碼。
- `題目`：可使用中文、英文或中英混合。
- 教師設定可讓後續大題選擇「不限單元，隨機抽題」或「與前面指定大題同單元」。

程式內也提供「下載空白範本」、「匯入題庫」及「匯出目前題庫」。

## Windows

1. 用 Chrome 或 Microsoft Edge 開啟上方 GitHub Pages 網址。
2. 第一次請保持網路連線。
3. 若頁面出現「安裝 App」，直接按下；也可從瀏覽器選單選「安裝應用程式」。
4. 安裝後從桌面或開始功能表開啟，再匯入題庫。
5. 若考試時要離線，請先斷網重新開啟一次確認可正常抽題。

## macOS

1. 用 Chrome 或 Safari 開啟 GitHub Pages 網址。
2. 第一次請保持網路連線。
3. Chrome 可選「安裝 App」；支援網站 App 的 Safari 版本可使用「加入 Dock」。
4. 開啟安裝好的 App，再匯入題庫。
5. 若需要離線，正式使用前先關閉網路重新開啟測試。

## Android

1. 用 Chrome 開啟 GitHub Pages 網址。
2. 第一次請保持網路連線。
3. 若頁面顯示「安裝 App」，直接按下；也可以從 Chrome 選單選「安裝應用程式」或「加入主畫面」。
4. 從手機主畫面的圖示開啟 App，再匯入題庫。
5. 若考試時要離線：開啟飛航模式 → 完全關閉 App → 從主畫面重新開啟。能正常抽題就代表離線準備完成。

## iPhone / iPad

1. 用 **Safari** 開啟 GitHub Pages 網址。
2. 第一次請保持網路連線。
3. 點 Safari 的「分享」按鈕 → **加入主畫面**。
4. 回到主畫面，從「術科考試抽題」圖示開啟，再匯入題庫。
5. 若考試時要離線：開啟飛航模式 → 完全關閉 App → 從主畫面重新開啟測試。

> iPhone / iPad 不一定會像 Android 一樣跳出「安裝 App」，使用 Safari 的「加入主畫面」即可。

## 如何更新 App？

**若目前版本使用正常，不需要特別更新。** 有需要使用新版功能，或目前版本遇到問題時，再更新即可。

1. 先讓裝置連上網路。
2. 開啟 App → **教師設定**。
3. 查看「版本與更新」。
4. 若有新版，會顯示目前版本與最新版本，並出現 **更新至 vX.X** 按鈕。
5. 按下更新後，程式會取得新版並重新開啟。
6. **原本匯入的題庫與抽題設定會保留。**

若目前離線，教師設定會顯示「目前離線」，不會要求更新。

## 如何刪除舊題庫？

如果只是想**換題庫，或把目前題庫和設定清掉**，不需要清 Cookie，也不用重新安裝 App：

1. 打開「術科考試抽題」。
2. 進入「教師設定」。
3. 按 **清除本機題庫與設定**。
4. 完成後即可重新匯入題庫。

## App 異常，想完全重新開始？

一般使用不需要做這一步。只有 App 發生異常，或希望恢復成第一次使用的狀態時才需要。

1. 刪除／解除安裝「術科考試抽題」App。
2. 在原本使用的瀏覽器中，刪除這個網站的「網站資料」或「儲存空間」。
3. 重新開啟 GitHub Pages 網址。
4. 再次安裝 App／加入主畫面。
5. 重新匯入題庫。

**只想更換題庫時，請直接使用教師設定裡的「清除本機題庫與設定」，不用做完整重置。**

## 離線使用前建議測試

**匯入題庫 → 關閉 App → 開飛航模式 → 從 App 圖示重新開啟 → 開始抽題 → 等倒數結束。**

如果以上都正常，就可以確認這台裝置能離線使用。

## 隱私

正式題庫不會因為匯入而上傳到此 GitHub repository。題庫與抽題規則只保存在目前使用的裝置；不同裝置不會自動同步。
